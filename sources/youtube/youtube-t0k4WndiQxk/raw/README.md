## Provenance

The human requester supplied this session with the video's English
auto-generated YouTube caption file (`.vtt`); outbound network access to
YouTube was not available in this environment. The `.vtt` uses YouTube's
rolling-caption format, where each cue repeats part of the previous cue's
text with word-level timestamps. It was mechanically deduplicated with a
script that keeps one timestamp per newly appearing word and regroups the
words into ~20-second lines, with no wording edited, paraphrased, or
corrected.

Per `sources/README.md`, the full transcript is not committed here.
`transcript-excerpts.txt` instead contains only the passages that
substantiate a claim in `../reviewed/claims.json`, in timecode order, with
`[... omitted ...]` markers between non-contiguous excerpts. Each line is
prefixed with its `[HH:MM:SS]` timecode so it can be matched back to a
specific claim's `sourceLocation`.

## Known limitations

- Auto-generated captions misspell names, brands, and numbers at points.
  Treat exact spellings and numbers as approximate unless cross-checked
  against the video.
- Timestamps mark when a word group *starts* appearing in the source
  caption stream, not exact sentence boundaries.
- This is course guidance from a single creator, not verified Meta
  documentation. See `../reviewed/claims.json` for classified, reviewed
  claims extracted from this transcript.
